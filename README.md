# Cold AC - Website

Simple React + Vite site for Cold AC HVAC & Electrical.

## Project Structure

- `src/` - React source files
- `public/` - Static assets
- `dist/` - Production build (generated)

## Scripts

- Install dependencies:

```bash
npm install
```

- Run development server:

```bash
npm run dev
```

- Build for production:

```bash
npm run build
```

- Preview production build locally:

```bash
npm run preview
```

- Run ESLint:

```bash
npm run lint
```

- Format source files with Prettier:

```bash
npm run format
```

## Notes

- Site uses Tailwind CSS and custom styles in `src/index.css`.
- The fixed header writes a CSS variable `--site-header-height` so main content is padded automatically.
